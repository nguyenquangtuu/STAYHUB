# STAYHUB - ỨNG DỤNG ĐẶT PHÒNG HOMESTAY

Hệ thống đặt phòng Homestay nghỉ dưỡng STAYHUB (Đồ án cuối kỳ môn Lập trình Ứng dụng).

- **Backend API**: Node.js + Express.js + MySQL (Xem chi tiết tại [backend/README.md](./backend/README.md))
- **Kho lưu trữ GitHub**: `https://github.com/nguyenquangtuu/STAYHUB.git`

## Khởi động nhanh Backend

```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

Kiểm tra API: mở file [backend/test.http](./backend/test.http) trên VS Code (dùng REST Client).
